# Generador de Esquemas Técnicos (SPAT / Perímetro / Torre / Equipos)

Aplicación web estática en HTML5, CSS y JavaScript (`<canvas>`) para generar esquemas técnicos y descargarlos en formato PNG:

1. **F12M - SPAT**: Diagrama de puesta a tierra con configuración de pozos (`PT01`–`PT06`), telurómetro y mediciones de resistencia.
2. **Esquema 1 - Perímetro**: Plano rectangular proporcional con puerta de acceso, cotas exteriores en metros y coordenadas inclinadas en las 4 esquinas (`A`, `B`, `C`, `D`).
3. **Esquema 2 - Torre**: Elevación proporcional con los 8 modelos de estructura en formato PNG sin deformación, cotas calibradas y respaldo de imagen personalizada.
4. **Esquema de Equipos en Torre**: Permite cargar de 1 a 4 fotos panorámicas, ordenar equipos según su altura (`RF`, `RRU`, `MW`, `GPS`), generar flechas y etiquetas rojas automáticamente (con ajuste fino arrastrando en pantalla) y descargar los PNG finales.
